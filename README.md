# موقع تَقِيّ (Taqy Web)

موقع تعريفي فاخر باللغة العربية لمشروع **تَقِيّ** لحماية البيئة الرقمية وحجب المحتوى غير اللائق والإباحي.

## الميزات المنفذة
- **هوية بصرية متطابقة مع الشعار**: ثيم داكن فاخر (Obsidian Black) مع لمسات ذهبية متوهجة مستوحاة من خط وزخارف الشعار.
- **عرض المنتجات**:
  - **متصفح الهاتف**: متاح للتحميل الفوري (APK) + ميزة "حظر المحتوى على كامل الهاتف" موسومة بأنها قيد التطوير مع شريط تقدم.
  - **أداة حماية ويندوز**: متاحة للتحميل الفوري (EXE) + ميزة "المتصفح الكامل لويندوز" موسومة بأنها قيد التطوير مع شريط تقدم.
- **التحميل المباشر**: تنزيل فوري للملفات عبر المتصفح مباشرة من مجلد `public/`.
- **أرقام خدمة العملاء**: خطوط ساخنة مصرية، نسخ سريع للرقم، واتصال مباشر وواتساب مع نافذة عائمة.
- **أقسام متكاملة**: Hero، مميزات الحماية، دليل التثبيت خطوة بخطوة، الدعم الفني، الأسئلة الشائعة، التذييل.

## التشغيل والتطوير
```bash
# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build

# معاينة بناء الإنتاج محلياً
npm run preview
```

## تعديل أرقام خدمة العملاء والروابط
جميع أرقام الهواتف والروابط والبيانات مجمعة في ملف:
`src/data/config.ts`
